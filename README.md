# Notes Storage App

A simple web-based Notes Storage App built to practice frontend web development.

## Features

- Create notes
- Edit notes
- Delete notes
- Store notes using browser Local Storage
- Notes remain saved after refreshing the page
- Simple and responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## How to Run

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Start creating and managing your notes.

## Project Purpose

This project was developed to strengthen my understanding of HTML, CSS, JavaScript, DOM manipulation, and browser Local Storage.
